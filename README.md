## ✨ Características

- Pruebas unitarias con Jest
- Verificación automática de funciones

## 🚀 Instalación y uso

Clona el repositorio:

```bash
git clone https://github.com/Ryujin010/EBAC-tests-con-jest.git
cd EBAC-tests-con-jest
```

Luego:

1. Instala las dependencias:
   ```bash
   npm install
   ```
2. Ejecuta las pruebas:
   ```bash
   npm test
   ```
